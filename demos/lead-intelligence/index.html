Da arquitetura à experiência

O que o projeto demonstra

IMPLEMENTADO NO CÓDIGO

Importação e auditoria

Tratamento de CSV/XLSX, classificação, trilhas de auditoria, revisão e referências verificáveis, com testes usando dados sintéticos.

IMPLEMENTADO NO CÓDIGO

Controle por organização

Firebase Authentication, perfis de acesso, regras de tenant e contratos de API voltados à segregação de dados e operações autorizadas.

SIMULAÇÃO CONTROLADA

Estúdio de IA e Karen

Versionamento de agentes e conhecimento, conteúdo aprovado e cenários comerciais sintéticos, sem disparos reais nem inferência paga.

ARQUITETURA PREPARADA

Backend e banco

FastAPI, SQLAlchemy, migrações Alembic e configuração para PostgreSQL/Cloud SQL. Integração e migrações reais seguem sujeitas à homologação.

PRÉVIA DOCUMENTADA

Frontend administrativo

Aplicação Next.js com interface de auditoria e Firebase Auth, com prévia publicada. Fluxos dependentes da API não estão demonstrados como operacionais.

PENDENTE DE VALIDAÇÃO

Integrações produtivas

Cloud Run integrado, PostgreSQL validado, inferência paga e conectores comerciais não são apresentados como entregas homologadas.

Documentação e código

Este estudo foi preparado a partir de documentos e arquivos de desenvolvimento. Os cenários e empresas mostrados na interface são inteiramente fictícios; nenhuma métrica de conversão ou eficácia de IA foi atribuída ao projeto.
