# Wanessa Karen | Portfólio Profissional

Portfólio pessoal desenvolvido para apresentar minha trajetória e projetos em **tecnologia, desenvolvimento web, marketing digital, dados e automação**.

O projeto também é um espaço para experimentar soluções de interface, organização de conteúdo e experiências responsivas.

**[Acessar o portfólio](https://portfolio-wanessa-sigma.vercel.app/)**

## Sobre o projeto

A interface segue a identidade **Creative Digital Lab**, com tema escuro, gradientes em roxo e ciano, tipografia de destaque, cartões informativos e transições discretas.

O site reúne apresentação profissional, áreas de atuação, rotina de trabalho, projetos, experiências, formação, certificações e contato. O conteúdo é organizado em seções navegáveis, com atenção à leitura em telas de diferentes tamanhos.

## Tecnologias utilizadas

| Tecnologia | Aplicação no projeto |
| --- | --- |
| **HTML5** | Estrutura e organização semântica das seções |
| **CSS3** | Estilos personalizados, gradientes, transições, animações e media queries |
| **Tailwind CSS** | Classes utilitárias, componentes e layouts responsivos |
| **JavaScript (vanilla)** | Menu móvel, navegação ativa e efeitos de entrada durante a rolagem |
| **Font Awesome** | Ícones da interface e dos links |
| **Google Fonts (Inter)** | Tipografia |
| **Git e GitHub** | Versionamento e publicação do código |
| **Vercel** | Hospedagem do site público |

O projeto é uma **página estática**, sem necessidade de servidor de aplicação ou processo de build para execução local. Tailwind CSS, fontes e ícones são carregados por CDN.

## Funcionalidades e cuidados de interface

- **Design responsivo:** adaptação de layout, imagens, tipografia e navegação para celular, tablet e desktop.
- **Navegação por seções:** links internos e indicação visual da seção ativa.
- **Menu móvel:** abertura e fechamento por botão, links de navegação e tecla Esc.
- **Interações visuais:** transições de entrada durante a rolagem e efeitos de hover.
- **Acessibilidade:** rótulos em controles, estados de foco visíveis e respeito à preferência por movimento reduzido (`prefers-reduced-motion`).
- **Metadados básicos:** título, descrição e configuração de viewport.

## Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/wanessakarenn-ship-it/Portfolio.git
   ```

2. Abra a pasta `Portfolio`.
3. Abra o arquivo `index.html` no navegador.

É necessária uma conexão com a internet para carregar as bibliotecas externas via CDN.
